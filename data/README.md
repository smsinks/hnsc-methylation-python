# Packaged research data

The inputs and numerical references belong to the reviewed HNSC manuscript
release dated 5 September 2026. `PROVENANCE.json` records input dimensions,
checksums, source names, provenance checks and license attribution.

`inputs/` contains the original cleaned methylation CSV, patient and sample
clinical tables, and RNASeqV2 RSEM expression matrix. Files retain their source
measurements and original text bytes. The clinical TSV files include the
original four metadata comment lines before the tabular header.

`source/` contains the original processed TCGA methylation matrix, the supplied
TCGA license notice and study metadata. These are processed public study data,
not raw methylation IDATs. `probe_annotations/` contains the four pinned
manifest and mask files used by the reviewed annotation quality rule.

Use `python tools/prepare_data.py` to restore the five original input files to
`data/prepared/`. The analysis calls the same utility automatically. Ordered
gzip parts, when present, are consecutive byte ranges of one original file.
Their decompressed contents must be concatenated in manifest order. They are
not independent tables and only the first part contains the original header.
The utility verifies the complete restored SHA-256 digest before use.

`reference/` contains faithful TSV exports of the original broader survival
screen and RNA-based KEGG GSEA workbook sheets. The survival table retains
21,887 original rows, including the 49 exact duplicates. The reviewed analysis
removes those duplicates before correcting 21,838 distinct tests. The original
GSEA export contains 290 pathways. These frozen summaries support Figures 6
and 8. They do not constitute a new Python reanalysis of the original legacy
survival and phenotype-permutation GSEA procedures.

`reference_results/` contains the reviewed statistical tables, figure source
data and cohort tables. Statistical values are preserved. Provenance JSON
files replace private machine paths with logical input identifiers. Keep this
baseline separate from results generated by a new run.

The supplied TCGA notice is copied exactly to `source/TCGA_LICENSE.txt`.
Third-party annotation files retain their upstream attribution and pinned
commit. No separate annotation license file was supplied in the reviewed
release and its upstream license could not be verified during packaging.
This package does not assert an additional license for those files.
